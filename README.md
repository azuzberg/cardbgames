# Лист — карточная игра в браузере

Игра один на один против бота: выбирайте карты, собирайте взятки и первыми наберите 21 очко. Интерфейс на русском языке, анимации раздачи и ходов, подробный подсчёт очков после каждого кона, история законченных партий. Текущая партия сохраняется при обновлении страницы и перезапуске сервера.

**Стек:** Python **3.13.3**, Flask, встроенная SQLite, HTML/CSS/JavaScript без сборщика и внешних CDN. SQLAlchemy не требуется. Отдельный сервер базы данных не нужен.

## Быстрый запуск

Установите [Python 3.13.3](https://www.python.org/downloads/release/python-3133/), распакуйте архив и откройте папку проекта.

**Windows:** запустите `run.bat`. Он создаст виртуальное окружение и установит зависимости. Если окно сразу закрылось, запустите файл из терминала, чтобы прочитать ошибку.

**Linux / macOS:**

```bash
bash run.sh
```

Если Python установлен под другим именем, укажите путь:

```bash
PYTHON_BIN=/путь/к/python3.13 bash run.sh
```

После запуска откройте в браузере **http://127.0.0.1:5000**. Остановка сервера — `Ctrl+C` в терминале. При первом запуске нужен доступ к PyPI для установки зависимостей; после установки сама игра работает без интернета.

### Ручная установка

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r requirements.txt
.venv/bin/python app.py
```

В Windows вместо `python3.13` используйте `py -3.13`, а вместо `.venv/bin/python` — `.venv\Scripts\python.exe`. Активация окружения не обязательна.

## Как играть

1. В лобби выберите игру против бота и начните партию. Сдатчик первого кона — бот, первым ходите вы. В следующих конах сдатчик меняется.
2. Нажмите на карту в своей руке, затем выделите нужные карты стола и подтвердите ход. Подсказка помогает подобрать допустимую взятку.
3. Туз стоит 1, числовые карты — по номиналу. Одна выбранная комбинация должна в сумме равняться вашей карте: например, `10` берёт `7 + 2 + туз`. Можно взять одну равную карту вместо суммы; приоритета у неё нет.
4. Валет, дама и король берут **одну** карту того же ранга. Картинки не участвуют в числовой сумме.
5. Если **выбранной картой** можно взять взятку, сбрасывать её нельзя. Другую карту, которой нечего взять, разрешено положить на стол. Сыгранная карта тоже входит во взятку.
6. После того как оба игрока использовали свои четыре карты, каждому сдаётся ещё четыре. Новые карты на стол при пересдаче не выкладываются.
7. После 48 ходов кон заканчивается. Оставшиеся карты стола получает последний взявший взятку. Если за кон никто ничего не взял, остаток получает сдатчик.

Взятки лежат рубашкой вверх; карты бота и порядок колоды скрыты. Бот выбирает допустимые ходы, оценивая размер взятки, трефы и призовые карты. Он использует только свою руку и открытый стол.

## Подсчёт очков

| Категория за кон | Очки |
| --- | --- |
| Больше взятых карт | 2 |
| Ровно по 26 карт | По 1 каждому |
| Больше треф | 1 |
| Взята 2♣ | 1 |
| Взята 10♦ | 1 |

При равенстве числа треф никто не получает очко за эту категорию. Бонуса за очистку стола нет. Номиналы используются для взяток, а итоговые очки начисляются только по таблице.

Партия заканчивается **после завершения кона**, когда хотя бы один игрок набрал 21 очко и суммарные счета различаются. Побеждает игрок с большим счётом. При равном счёте 21 или выше играется ещё один кон. Окно результата показывает категории, очки за кон и общий счёт.

## Сохранения и настройки

SQLite создаётся автоматически в `instance/cardbgames.sqlite3`. В ней хранятся текущие партии и результаты. Браузер получает случайный идентификатор в cookie; один профиль браузера соответствует одному сохранению. Разные браузеры играют независимо. Очистка cookie лишает браузер доступа к прежнему сохранению. Учётных записей и сетевой игры пока нет.

Можно задать переменные окружения:

| Переменная | Назначение |
| --- | --- |
| `PORT` | Порт HTTP-сервера, по умолчанию `5000` |
| `CARDBGAMES_DATABASE` | Путь к файлу SQLite, по умолчанию `instance/cardbgames.sqlite3` |

Перед резервным копированием базы остановите сервер. Для полного сброса локальных данных остановите сервер и удалите файл базы из `instance/`.

Сервер запускается на локальном интерфейсе без режима отладки. Этот проект предназначен для локальной разработки; для публикации в интернете потребуется отдельная настройка HTTPS и серверного развёртывания.

## Проверка проекта

Из папки проекта:

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Проверяются комбинации взяток, обязательность взятки, раздачи, подсчёт очков, конец партии, сохранение в SQLite и защита от повторного хода. Браузерная проверка описана в `TESTING.md`.

## Структура

```text
app.py               HTTP-сервер и API
game.py              правила и стратегия бота
storage.py           сохранения SQLite
templates/index.html страница игры
static/              интерфейс и анимации
tests/               автоматические проверки
requirements.txt     точные версии зависимостей с хешами
run.sh / run.bat     запуск
```

Основные точки для следующего этапа: правила и стратегия в `game.py`, внешний вид в `static/style.css`, поведение и анимации в `static/app.js`.
