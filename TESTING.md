# Проверка игры

Основные тесты не требуют дополнительных пакетов. После установки проекта выполните:

```bash
.venv/bin/python -m unittest discover -s tests -v
```

В Windows замените `.venv/bin/python` на `.venv\Scripts\python.exe`.

23 теста проверяют:

- числовые комбинации, туз, картинки, обязательную взятку для выбранной карты;
- запрет повторных карт и ошибочных ходов, независимую проверку поиска комбинаций;
- раздачи, ровно 48 ходов и сохранность всех 52 карт за кон;
- все категории очков, остаток стола, смену сдатчика и ничью при достижении цели;
- 30 полных моделируемых партий до победы;
- SQLite после перезапуска, историю, независимые браузерные сессии;
- повторные и одновременные запросы: один ход записывается только один раз.

## Проверка работающего сервера

Запустите `run.sh` или `run.bat`, затем во втором терминале:

```bash
.venv/bin/python tests/server_smoke.py
```

Скрипт получает начальную раздачу, делает ход игрока и бота и проверяет сохранение. Он использует отдельную cookie-сессию и не затрагивает вашу текущую партию. Другой порт можно указать через `--url http://127.0.0.1:5001`.

## Полная проверка в браузере

Это дополнительная проверка для разработки. Playwright не нужен для самой игры.

```bash
.venv/bin/python -m pip install playwright==1.62.0
.venv/bin/python -m playwright install chromium
.venv/bin/python tests/browser_smoke.py
```

Если Chromium уже установлен в системе, можно указать его путь:

```bash
.venv/bin/python tests/browser_smoke.py --chromium /usr/bin/chromium --screenshots /tmp/cardbgames-screenshots
```

Скрипт запускает сервер на свободном порту с временной базой, проверяет лобби и правила, играет целую партию через кнопки интерфейса, перезагружает страницу, проверяет результат и историю. Отдельно проверяет мобильный интерфейс, ширины 320/390/768 px и видимые анимации раздачи и взятки. После проверки тестовый сервер останавливается, временная база удаляется. Снимки экрана создаются только при передаче `--screenshots`.

## Что проверено при подготовке архива

Проверки выполнены на Linux, Python **3.13.3**, SQLite **3.47.1** и Chromium:

- все 23 автоматических теста проходят;
- две полные партии через интерфейс: в одной победил бот (25:15), в другой — игрок (23:17); каждая заняла 8 конов и 192 хода игрока;
- сохранение после обновления страницы, итоговый счёт и история корректны;
- лобби, стол и результаты на компьютере и мобильном экране работают;
- анимации раздачи и взятки отображаются; режим уменьшенной анимации поддерживается;
- ошибок JavaScript в этих сценариях нет.

Windows-скрипт включён в проект; выполнение в Windows отдельно не проверялось.
